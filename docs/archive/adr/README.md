# Archived ADRs (superseded by their DEC counterparts)

This directory is the archive of the removed ADR (Architecture Decision
Record) artifact type (GitHub issue #46, feat-46-remove-adr). The ADR
domain package, its MCP tools/resources/prompts, and the `specmgr adr-toc`
command are gone; no new ADRs are created — new decisions are DEC
documents.

Every ADR in this archive is now a DEC at `docs/dec/<same uuid>-<same
slug>.md`: the conversion reused each ADR's `id` and file name, so a
cross-reference to a decision by UUID resolves to its DEC. The preserved
generated table of contents is `adr-toc.md`, and the "Convert an ADR to a
DEC" SOP is archived at `docs/archive/sop/`.

The ADR bodies here are frozen historical prose (the fidelity gate of
issue #46 compares the converted DECs against them) — do not edit them.
