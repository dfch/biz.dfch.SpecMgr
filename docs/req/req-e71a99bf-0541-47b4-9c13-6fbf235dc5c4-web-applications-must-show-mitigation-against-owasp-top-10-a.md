# Web Applications Must Show Mitigation Against OWASP Top 10 Attacks

Web applications must implement security controls addressing all OWASP Top 10 vulnerabilities.

## Description

OWASP Top 10 represents the most critical security risks to web applications. This requirement ensures that all web applications incorporate appropriate security controls to protect against these known threats, reducing the risk of data breaches, unauthorized access, and system compromise.

## Characteristics

1. Security
2. Reliability
3. Maintainability

## Level

<!-- RFC 2119 Requirement Keyword. Mandatory. -->
MUST

## Priority

<!-- A number between 0 and 99. Lower number is higher priority. -->
50

## Source

OWASP Foundation

## More Information

OWASP Top 10 consists of the following vulnerability categories:
1. Broken Access Control
2. Cryptographic Failures
3. Injection
4. Insecure Design
5. Security Misconfiguration
6. Vulnerable and Outdated Components
7. Identification and Authentication Failures
8. Software and Data Integrity Failures
9. Security Logging and Monitoring Failures
10. Server-Side Request Forgery (SSRF)

Each application must implement appropriate mitigations based on its attack surface and threat modeling results.
