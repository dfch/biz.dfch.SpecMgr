# `biz.dfch.specmgr.prb.models`

Problem Statement (PRB) models -- Pydantic schema powered by the generic ``models/md`` engine.

Mirrors ``tsk/models``/``qa/models``'s layout: versioned sub-packages (``v1``,
...) holding the frontmatter/body classes, the document wrapper, and the
parser for ``prb`` documents.
