# Shower vs Bath Tub

## Context and Problem Statement

We need to decide whether to install a shower or a bath tub. The decision should account for installation effort, cost, and environmental impact.

## Considered Options

Shower, Bath Tub

## Decision Outcome

Chosen option: "Shower", because it is easier to install, costs less, and is more environmentally friendly than a bath tub.

## Pros and Cons of the Options

### Option 1: Shower

* Good, because it is easier to install
* Good, because it costs less
* Neutral, because environmental impact was not specifically evaluated (assumed favorable relative to bath tub)

### Option 2: Bath Tub

* Bad, because it is less environmentally friendly
* Neutral, because installation and cost were not specifically evaluated relative to shower
* Bad, because heating and using the larger volume of water needed to fill a bath tub consumes more energy than a shower
